# Atelier Moulures

Calculette de calepinage de cadres muraux, plinthes et corniches, adaptée au mobile.

## Utilisation

Activer GitHub Pages dans **Settings → Pages → Deploy from a branch → main → /(root)**. L'application sera disponible à https://jm408.github.io/Atelier-moulures/ .

## Fonctionnalités

- Dimensions du mur, plinthes et corniche
- Nombre de cadres, rangées, marges et espacements
- Aperçu SVG à l'échelle
- Liste des coupes à 45°, métrage et estimation des barres
- Sauvegarde locale des paramètres et fonctionnement hors ligne après installation
